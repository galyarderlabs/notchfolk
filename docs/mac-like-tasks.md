# Mac-like tasks (MacOs-CC integration)

Task breakdown for the plan in `mac-like-plan.md`. No phase starts implementation
until its tasks are listed here and Galih has seen the plan. Every task names the
exact Notchfolk file to touch, the exact MacOs-CC reference code to follow, and
the exact API. If a task does not name those, it is not ready to implement.
Phase 1 was implemented before this plan existed — its tasks are listed
retroactively and marked done so the record is complete.
